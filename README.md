# Замер скорости скачивания

Консольный скрипт на Python делает несколько запросов подряд к одному адресу, дожидается полного ответа на каждый и считает среднее время запроса, общий объём и скорость скачивания

Python 3.10+, только стандартная библиотека, ставить ничего не нужно

## Запуск

```bash
python speedtest.py https://proof.ovh.net/files/10Mb.dat
```

| Параметр | Что делает | По умолчанию |
|---|---|---|
| `url` | адрес, к которому стучаться (например, большая картинка или тестовый файл) | обязательный |
| `-n`, `--count` | число запросов | 10 |
| `-t`, `--timeout` | тайм-аут одного запроса, секунды | 30 |

На Windows, если в консоли кракозябры вместо русского текста: `python -X utf8 speedtest.py ...`

## Пример вывода

```text
Скачиваю https://proof.ovh.net/files/10Mb.dat 10 раз(а) подряд
  запрос  1: 2.869 с, 10.49 МБ
  ...
  запрос 10: 2.726 с, 10.49 МБ

Среднее время запроса: 2.770 с
Всего скачано: 104.86 МБ (104857600 байт)
Скорость: 30.28 Мбит/с (3.79 МБ/с)
```

## Единицы

- Время в секундах
- Объём в десятичных единицах: 1 МБ = 1 000 000 байт, плюс точное число байт
- Скорость в **мегабитах в секунду** (1 Мбит/с = 1 000 000 бит/с), как её указывают провайдеры; в скобках то же в мегабайтах в секунду

## Как считается

- Запросы идут строго последовательно, каждый читается до конца потоком по 64 КБ, поэтому большие файлы не загружаются в память целиком
- Время запроса: от отправки до получения последнего байта (`time.perf_counter`), то есть включает установку соединения и ожидание первого байта
- Среднее время: сумма времени запросов / число запросов
- Скорость: все скачанные байты × 8 / суммарное время запросов
- Заголовок `Accept-Encoding: identity` просит сервер не сжимать ответ, чтобы считать реально переданные байты; `Cache-Control: no-cache` просит не отдавать ответ из промежуточного кэша

## Ошибки

Ошибка HTTP (например, 404 или 429), недоступный адрес, тайм-аут и пустой ответ выводятся понятным сообщением, скрипт завершается с кодом 1. Неверный адрес или число запросов меньше 1 отсекаются до начала замера

## Тесты

```bash
python -m unittest -v
```

Тесты поднимают локальный HTTP-сервер, интернет не нужен. Проверяют: ровно 10 последовательных запросов и подсчёт байт, формулы среднего и скорости, вывод в консоль, ошибку HTTP, ошибку соединения, пустой ответ и неверные аргументы
